# Telegram PC Controller

> 💡 **定位：这是一款极简的方便型快捷助手。**
> ⚠️ **说明：我们不是像 OpenClaw 或 OpenInterpreter 那样的全能操作型 AI 机器人。没有繁琐臃肿的重度操作与未知风险，只有精确控制的核心预设指令——一切只为极致的方便与安全！**

这是一款基于 Python 和 C++ 编写的 Windows 电脑远程控制和智能管家机器人。
你可以通过 Telegram 随时随地向它发送自然语言（不需要死记硬背指令），它就能听懂你的意图，并帮你完成对应的电脑操作，甚至**从物理底层突破 Windows 锁屏界面为你解锁电脑**！

## 🌟 核心功能

- **🤖 自然语言理解**：内置接入任何兼容 OpenAI 格式的大模型 API（默认配置 DeepSeek），你说“帮我关机”、“声音太吵了”、“截个图看看”它都能听懂。
- **🔓 物理级锁屏解锁**：独家自研 C++ Credential Provider（凭据提供程序），支持在 Windows 锁屏界面接收 Telegram 远程指令，瞬间强行注入密码完成解锁.
- **📸 屏幕监控**：一键获取当前电脑屏幕的实时截图。
- **🔌 电源及系统管理**：支持关机、重启、睡眠、静音、精确调节音量（如“音量调到30%”）。
- **🧹 桌面整理**：一键关闭所有非系统窗口、最小化所有窗口。
- **🛡️ 绝对安全**：代码强制校验 Telegram User ID，即使别人知道你的机器人账号，也无法发送任何指令。Windows 解锁密码仅保存在本地，绝不上云。
- 输入：你能干啥，获取所有功能列表

## 🛠️ 部署指南

### 第一步：准备必要账号和密钥

1. **申请 Telegram 机器人 (Bot Token)**
   - 在 Telegram 中搜索 `@BotFather`，发送 `/newbot`。
   - 按照提示为你的机器人起名，并获取类似 `123456789:ABCDefg_hIjkLmnopQRstuvWXYZ` 的 **Bot Token**。
2. **获取你的 Telegram 账号 ID (User ID)**
   - 在 Telegram 中搜索 `@userinfobot`，点击 Start，它会回复你的 ID（一串纯数字，例如 `12345678`）。记录下来，这用于权限白名单。
3. **准备大模型 API Key**
   - 你可以使用 DeepSeek、智谱、阿里云或者原版 OpenAI 的 API。
   - 获取你的 API Key（例如 `sk-xxxxxx`），以及接口地址（Base URL）和模型名称。

### 第二步：配置运行环境

1. **安装 Python 3**
   - 确保你的 Windows 已安装 Python 3.8+，并在安装时勾选了 `Add Python to PATH`。
2. **安装依赖库**
   - 下载本仓库源码后，在源码目录打开命令行（Terminal），运行：
     ```bash
     pip install -r requirements.txt
     ```

### 第三步：初次运行与配置

1. 运行 `gui.pyw`：
   - 正常情况下直接 **双击** 即可运行。
   - 如果双击没有反应或用记事本打开了，请右键点击 `gui.pyw` -> 选择 **“打开方式”** -> 选择 **“Python (default windowed)”**。
   - 💡 **提示**：如果在“打开方式”里找不到 Python 选项，说明你**还没安装 Python**！请一定要先看上面的【第二步：配置运行环境】去安装它。
   
   ![打开方式演示](open_method.png)
2. 在弹出的图形界面中点击 **“API 接口设置”**：
   - 填入你刚才准备好的 `AI API Key`、`AI Base URL`、`AI Model Name`。
   - 填入你的 `Telegram Bot Token` 和 `Your Telegram User ID`。
   - 点击保存，此时机器人会自动开始运行，并在系统右下角托盘显示。
3. （可选）勾选主界面的 **“开启最高权限开机自启”**，这样以后每次登录 Windows 后，它都会在后台静默运行。

### 第四步：配置“高级锁屏解锁”功能（重头戏）

如果你希望在锁屏界面也能用手机一键解锁电脑：
1. 在主界面点击 **“锁屏解锁设置”**。
2. 填入你当前 Windows 电脑的 **登录用户名** 和 **登录密码**。
   > ⚠️ **重要提醒**：如果你平时是用 **Windows Hello 的 PIN 码**解锁屏幕的，这里的密码**必须输入你的微软账户密码**，千万不要输入 PIN 码！（如果你本来就是用普通的本地密码登录，则直接输入本地密码即可）。
3. 点击 **“保存凭据”**。
4. 点击 **“一键安装/更新解锁驱动”**（此步骤会请求管理员权限）。
5. 安装成功后，按下 `Win + L` 锁定屏幕。
6. 打开手机上的 Telegram，对你的机器人发送“帮我解锁”，看着屏幕瞬间闪回桌面吧！

## ⚠️ 注意事项

- **关于自启与系统安全**：本程序的自启机制基于“登录后最高权限计划任务”实现。如果你需要修改代码或重新部署，务必不要在系统的 `Startup` 文件夹里放置额外的快捷方式，否则会产生两个实例冲突。
- **关于锁屏驱动卸载**：如果你不想用解锁功能了，可以运行 `TGUnlockProvider/uninstall.bat` 卸载底层驱动。
- **隐私保护**：本源码已剥离所有个人敏感信息。所有的配置信息（Token、密码）都会保存在你本地生成的 `config.json` 文件中，不会上传。
